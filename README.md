# Synthopia Launcher

The Synthopia Launcher lets you create videos on [Synthopia](https://www.synthopia.art) with your own LTX account. It runs quietly in the Windows system tray, and you keep using Synthopia in your normal browser.

## Download

**[Download the latest version for Windows](https://github.com/ychbika/synthopia-launcher/releases/latest/download/Synthopia-Launcher-Setup.exe)**

All versions are listed on the [Releases](https://github.com/ychbika/synthopia-launcher/releases) page.

## How it works

1. Install the launcher. It starts right away and appears in the system tray.
2. In Synthopia, open the credits card and choose **Connect**. Your browser opens LTX's sign-in page. Approve the connection there.
3. Create as usual. The launcher sends your video requests to LTX and passes the finished videos back to Synthopia.

## Your account and privacy

- The launcher only accepts requests from Synthopia's own web pages, and only from this computer.
- Your LTX sign-in is stored encrypted on your computer, using Windows' protected storage. It is never sent to Synthopia.
- Synthopia only receives links to the finished videos.
- Generations use your own LTX credit. To add credit, right-click the tray icon and choose **Add LTX credit**.

## Managing the launcher

Right-click the tray icon to:

- See which LTX account is connected
- Disconnect LTX
- Turn **Start with Windows** on or off
- Quit

To remove the launcher, open Windows **Settings → Apps → Installed apps**, find **Synthopia Launcher**, and choose **Uninstall**.

## Windows warnings

The installer is not code-signed yet. Windows SmartScreen may say the publisher is unknown. If so, choose **More info**, then **Run anyway**.

On PCs with Smart App Control turned on, Windows blocks unsigned apps and offers no way to run them. A signed version is planned.
